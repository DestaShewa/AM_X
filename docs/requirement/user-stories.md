# AMX User Stories

## Visitor Stories

### US-01

As a visitor, I want to view AMX experiences so that I can understand what is available.

### US-02

As a visitor, I want to submit my travel date and group size so that AMX can plan an appropriate experience.

### US-03

As a visitor, I want to provide my budget and interests so that AMX can recommend suitable options.

### US-04

As a visitor, I want one clear quotation so that I understand the total expected cost.

### US-05

As a visitor, I want to contact AMX easily so that I can ask questions before booking.

### US-06

As a visitor, I want clear inclusions and exclusions so that I know what I am paying for.

### US-07

As a visitor, I want to provide feedback after my trip so that AMX can improve its service.

## Admin Stories

### US-08

As an AMX administrator, I want to see new inquiries so that I can respond quickly.

### US-09

As an AMX administrator, I want to manage customer records so that customer information is organized.

### US-10

As an AMX administrator, I want to manage providers so that I can coordinate services efficiently.

### US-11

As an AMX administrator, I want to check provider availability so that I do not promise unavailable services.

### US-12

As an AMX administrator, I want to create quotations so that customers receive clear prices.

### US-13

As an AMX administrator, I want to track booking status so that I know the current state of every trip.

### US-14

As an AMX administrator, I want to record payments so that financial information remains accurate.

### US-15

As an AMX administrator, I want to record follow-ups so that customer requests are not forgotten.

### US-16

As an AMX administrator, I want to record reviews and complaints so that service quality can be improved.
