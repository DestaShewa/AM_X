# AMX Requirements Prioritization

**Method:** MoSCoW

## 1. Must Have

These are required for the MVP.

* Public AMX website
* Package information
* Inquiry submission
* Inquiry management
* Customer management
* Provider management
* Provider verification records
* Package management
* Quotation creation
* Quotation total calculation
* Booking management
* Booking status
* Payment recording
* Admin authentication
* WhatsApp/contact integration
* Basic security
* Mobile responsiveness
* Database backup

## 2. Should Have

Important but not required to prove the initial business model.

* Customer reviews
* Complaint management
* Follow-up management
* Basic analytics
* Basic revenue reporting
* PDF quotation
* Amharic support
* SEO improvements
* Error monitoring

## 3. Could Have

Useful improvements if time and resources allow.

* Automated email notifications
* Automated WhatsApp templates
* Customer accounts
* Provider availability calendar
* Provider rating system
* Advanced analytics
* Online payment integration

## 4. Won't Have in MVP

Explicitly excluded from the initial MVP:

* Provider self-service dashboard
* Native mobile application
* AI chatbot
* Live vehicle tracking
* Automatic hotel availability
* Large tourism marketplace
* Multi-city marketplace
* Automated commission splitting
* Complex online payment infrastructure

## 5. Prioritization Principle

When requirements conflict, priority shall be given to:

1. Business validation
2. Customer trust
3. Operational reliability
4. Security
5. MVP simplicity
6. Future scalability
